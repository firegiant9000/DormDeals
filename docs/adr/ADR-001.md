# ADR-001: Framework and Database Selection

**Date:** 2025-10-17  
**Decision Makers:** DormDeals Team  
**Status:** Superseded by [ADR-002](ADR-002.md) (the backend moved to Firebase)

## 1. Context
The application requires a backend that is reliable and maintainable to support the frontend. The backend must handle user authentication, item listings, search and filter functionalities, and real-time interactions between users. It should also integrate with a structured relational database to manage data such as users, listings, transactions, messages, and preferences.

## 2. Decision
We have decided to use **Express.js** as our backend framework and **MySQL** as our database management system.

### Framework: Express.js
- Will be used to build the REST API for handling user authentication, item listings, and other backend services.

### DBMS: MySQL
- Will be used as the relational database to store user accounts, product listings, and transaction records.

## 3. Consequences
- **Positive:**  
  - Clear separation between frontend (React) and backend (Express).  
  - Scalable API structure with a reliable database.  
  - Easier deployment using a common JavaScript stack.

- **Negative:**  
  - Requires backend setup and API design.  
  - Manual handling of SQL schema and migrations if not using an ORM.
